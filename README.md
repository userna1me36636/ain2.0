# ain2.0
ain an all in one discord bot
## Overview

This all-in-one Discord bot brings server management, community engagement, moderation, music, and recovery tools into one powerful package. It is built for communities that want one bot to handle everyday server operations without juggling multiple separate bots.

### Key Features

- **Economy System**: Let members earn, save, deposit, withdraw, and spend virtual currency with daily, weekly, work, shop, and balance commands.
- **Server Backup & Restore**: Generate secure backup codes that save roles, channels, categories, permissions, and bot settings so you can restore a server layout if something goes wrong.
- **Moderation Tools**: Ban, kick, timeout, warn, purge messages, lock channels, set slowmode, and manage roles with permission-protected commands.
- **Anti-Nuke & Automod**: Protect your server from raids, destructive actions, invite links, spam, banned words, and unwanted links.
- **Welcome & Autorole**: Greet new members, send leave messages, and automatically assign roles when users join.
- **Ticket System**: Create private support tickets, add or remove users, close tickets, and manage support channels.
- **Join-to-Create Voice Channels**: Let users create temporary voice channels with ownership controls like rename, lock, hide, limit, permit, and reject.
- **Music Playback**: Play, pause, resume, skip, loop, queue, remove, and stop music with clean Discord commands.
- **Giveaways, Levels, Logs, Reaction Roles & Utilities**: Run giveaways, track XP, configure server logs, assign roles with reactions, create polls, generate embeds, and more.

Designed with slash commands, modular cogs, SQLite storage, and configurable settings, this bot is easy to run, simple to manage, and flexible enough for growing Discord communities.
